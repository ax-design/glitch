Glitch Canvas

A web component for real-time glitch art effects with buffer-based playback. Supports JPEG and PNG glitch domains with per-frame random domain selection.

1. Registration

Include the build script and call register() to define the custom element.

<script src="build/main.js"></script>
<script>
  AxGlitch.register();
</script>

<glitch-canvas></glitch-canvas>

An empty canvas. Load an image to begin.

2. Loading Images

2a. src attribute

Set src to load an image by URL. The image is fetched via fetch() and requires CORS headers.

<glitch-canvas
  src="example.jpg"
  crossorigin="anonymous"
  buffer-size="1">
</glitch-canvas>

2b. load() method

Call load(url) programmatically. Returns a Promise that rejects on network or CORS errors.

glitchCanvas.load('example.jpg')
  .then(function() { /* ready */ })
  .catch(function(err) { console.error(err); });

2c. cloneFrom() with <img>

Capture from an existing <img> element:

var image = document.getElementById('my-img');
glitchCanvas.cloneFrom(image);

2d. cloneFrom() with <canvas>

Works with HTMLCanvasElement, HTMLImageElement, and HTMLPictureElement.

glitchCanvas.cloneFrom(canvasElement);

3. Attributes

3a. fps

Playback frame rate. Default is 8.

<glitch-canvas fps="8"></glitch-canvas>

// Or set via property:
glitchCanvas.fps = 12;

3b. buffer-size

Number of internal frame buffers. More buffers means smoother variation during playback. Default is 4.

<glitch-canvas buffer-size="4"></glitch-canvas>

// Or set via property:
glitchCanvas.bufferSize = 6;

3c. quality

JPEG encoding quality (0.01 to 1.0). Lower quality produces coarser JPEG artifacts, making glitch effects more dramatic. Only applies to the JPEG domain. Default is 0.95.

<glitch-canvas quality="0.3"></glitch-canvas>

// Or via property:
glitchCanvas.quality = 0.5;

4. Domain Management

Glitch Canvas supports two glitch domains: JPEG and PNG. Each domain has its own set of glitch types. The JPEG domain is active by default after loading an image. You can enable the PNG domain alongside it, or use either one alone.

4a. Enabling the PNG Domain

Enable the PNG domain to use PNG-specific glitch effects. Pass filterType to control how corruption propagates (see below).

glitchCanvas.cloneFrom(sourceImage);

// Enable PNG domain with default (adaptive) filter
glitchCanvas.enableDomain('png');

// Or force a specific filter type
glitchCanvas.enableDomain('png', {
  filterType: G.PngFilterType.Sub,
});

glitchCanvas.addGlitch(new G.FilterDataGlitch(
  new G.Position(30),
  new G.GlitchValue(128),
), 'png');

4b. Filter Type and Propagation Direction

The filter type used during PNG encoding determines how byte corruption propagates when the decoder reconstructs pixels. This is an encoding option, not a glitch parameter.

G.PngFilterType.None    // no propagation, single pixel
G.PngFilterType.Sub    // horizontal (left to right)
G.PngFilterType.Up     // vertical (top to bottom)
G.PngFilterType.Average // diagonal (top left to bottom right)
G.PngFilterType.Paeth  // wide area (right and down)
// Force Sub filter for horizontal glitch propagation
glitchCanvas.enableDomain('png', {
  filterType: G.PngFilterType.Sub,
});

4c. Multi-Domain Playback

When both JPEG and PNG domains are active, each frame randomly selects one domain. This produces mixed JPEG and PNG glitch effects in a single animation.

glitchCanvas.cloneFrom(sourceImage);

// JPEG domain is active by default after cloneFrom()
glitchCanvas.addGlitch(new G.ChaosGlitch(
  new G.Position(50),
  new G.GlitchValueCollection(
    [{ value: 200 }, { value: 150 }],
    G.DistributionKind.Sequential,
  ),
), 'jpeg');

// Enable PNG domain alongside JPEG
glitchCanvas.enableDomain('png', {
  filterType: G.PngFilterType.Up,
});
glitchCanvas.addGlitch(new G.FilterDataGlitch(
  new G.Position(40),
  new G.GlitchValue(128),
), 'png');

glitchCanvas.play(); // frames alternate randomly

5. Single-Value Glitch Types

5a. WidthGlitch (JPEG)

Overwrites the image width byte in the SOF0 segment. Accepts a single GlitchValue only.

var glitch = new G.WidthGlitch(
  new G.Position(0),
  new G.GlitchValue(200),
);
glitch.randomizeMode = 'val';
glitchCanvas.addGlitch(glitch);

5b. QuantumGlitch (JPEG)

Substitutes a byte in the DQT quantization table. Single value only. Lower quality produces larger quantization values, making the effect visible.

<glitch-canvas quality="0.3"></glitch-canvas>

var glitch = new G.QuantumGlitch(
  new G.Position(50),
  new G.GlitchValue(80),
);
glitch.randomizeMode = 'both';
glitchCanvas.addGlitch(glitch);

5c. QuantumGlitch + Quality Randomization (JPEG)

Set qualityRange to randomize JPEG quality along with glitch parameters. Each call to randomize() re-encodes the source at a new quality, producing different JPEG structure and quantization values.

glitchCanvas.qualityRange = { min: 0.1, max: 0.6 };

var glitch = new G.QuantumGlitch(
  new G.Position(50),
  new G.GlitchValue(80),
);
glitch.randomizeMode = 'both';
glitchCanvas.addGlitch(glitch);

// randomize() now also randomizes quality
// and re-encodes the JPEG at the new quality
glitchCanvas.randomize();

5d. GraftGlitch (PNG)

Changes filter type bytes without re-filtering the data. The decoder uses the wrong filter to reconstruct pixels, producing algorithmic color distortion across entire scanlines. Supports single or multi-value for targeting multiple scanlines.

var glitch = new G.GraftGlitch(
  new G.Position(20),
  new G.GlitchValueCollection(
    [{ value: 4 }, { value: 2 }, { value: 3 }, { value: 1 }],
    G.DistributionKind.Uniform,
  ),
);
glitch.randomizeMode = 'both';
glitchCanvas.addGlitch(glitch, 'png');

5e. CustomFilterGlitch (PNG)

Re-encodes scanlines with a custom filter function instead of the standard PNG filters. The decoder still uses standard filter reconstruction, creating systematic algorithmic deviation across the image. Optionally target a scanlineRange to affect only some rows.

// Custom filter: XOR each byte with its left neighbor
var customEncoder = function(data, prev, sampleSize) {
  var result = new Uint8Array(data);
  for (var i = sampleSize; i < data.length; i++) {
    result[i] = (data[i] ^ data[i - sampleSize]) & 0xff;
  }
  return result;
};

var glitch = new G.CustomFilterGlitch(customEncoder);
glitchCanvas.addGlitch(glitch, 'png');

5f. Filter Type Comparison (PNG)

Same glitch, different forced filter type during encoding. Each uses DensityValue(0.05) to target 5% of all pixels automatically.

None

Sub

Up

Average

Paeth

var density = new G.DensityValue(0.05, { min: 50, max: 230 });

var filters = [
  [G.PngFilterType.None, 'None'],
  [G.PngFilterType.Sub,  'Sub'],
  [G.PngFilterType.Up,   'Up'],
  [G.PngFilterType.Average, 'Average'],
  [G.PngFilterType.Paeth,   'Paeth'],
];
filters.forEach(function([type, name]) {
  var glitch = new G.FilterDataGlitch(
    new G.Position(50), density,
  );
  glitch.randomizeMode = 'both';
  glitchCanvas.addGlitch(glitch, 'png');
  glitchCanvas.enableDomain('png', { filterType: type });
});

6. Multi-Value Glitch Types

6a. ChaosGlitch (JPEG, single value)

Substitutes bytes in the SOS scan data. Can use a single GlitchValue:

var glitch = new G.ChaosGlitch(
  new G.Position(30),
  new G.GlitchValue(200),
);
glitch.randomizeMode = 'val';
glitchCanvas.addGlitch(glitch);

6b. ChaosGlitch (JPEG, sequential distribution)

With GlitchValueCollection and sequential distribution, entries are written to consecutive pool indices.

var collection = new G.GlitchValueCollection(
  [
    { value: 200 },
    { value: 150 },
    { value: 100 },
  ],
  G.DistributionKind.Sequential,
);
collection.valueRange = { min: 50, max: 200 };

var glitch = new G.ChaosGlitch(
  new G.Position(40),
  collection,
);
glitch.randomizeMode = 'val';

6c. ChaosGlitch (JPEG, random distribution)

Random distribution scatters entries within a spread range around the base position.

var collection = new G.GlitchValueCollection(
  [
    { value: 200 },
    { value: 180 },
    { value: 160 },
  ],
  G.DistributionKind.Random,
);
collection.countRange = { min: 2, max: 6 };
collection.valueRange = { min: 50, max: 220 };
collection.spread = { min: 0, max: 100 };

var glitch = new G.ChaosGlitch(
  new G.Position(50),
  collection,
);
glitch.randomizeMode = 'both';

6d. ChaosGlitch (JPEG, uniform distribution)

Uniform distribution spaces entries evenly across the full pool, giving maximum coverage.

var collection = new G.GlitchValueCollection(
  [
    { value: 200 },
    { value: 180 },
    { value: 160 },
    { value: 140 },
  ],
  G.DistributionKind.Uniform,
);
collection.valueRange = { min: 50, max: 220 };

var glitch = new G.ChaosGlitch(
  new G.Position(20),
  collection,
);
glitch.randomizeMode = 'both';

6e. HuffmanGlitch (JPEG)

Substitutes bytes in the DHT AC Huffman symbol table. Supports both single and multi-value.

var collection = new G.GlitchValueCollection(
  [
    { value: 128 },
    { value: 64 },
    { value: 192 },
  ],
  G.DistributionKind.Random,
);
collection.valueRange = { min: 0, max: 200 };
collection.spread = { min: 0, max: 50 };

var glitch = new G.HuffmanGlitch(
  new G.Position(30),
  collection,
);
glitch.randomizeMode = 'both';

6f. FilterDataGlitch (PNG)

Replaces bytes in decompressed filtered scanline data. Propagation direction depends on the filter type used during encoding. Use DensityValue to auto-generate sites proportional to image size.

var density = new G.DensityValue(0.05, { min: 50, max: 230 });

var glitch = new G.FilterDataGlitch(
  new G.Position(20),
  density,
);
glitch.randomizeMode = 'both';
glitchCanvas.addGlitch(glitch, 'png');

6g. DefectGlitch (PNG)

Deletes bytes from filtered data and shifts all subsequent bytes forward (like pnglitch's Defect). This cascading shift misaligns scanline boundaries — the decoder interprets shifted data with potentially wrong filter types, producing progressive displacement artifacts. Filter type bytes are clamped to 0–4 after the shift to keep the PNG decodable.

var density = new G.DensityValue(0.03);

var glitch = new G.DefectGlitch(
  new G.Position(30),
  density,
);
glitch.randomizeMode = 'both';
glitchCanvas.addGlitch(glitch, 'png');

6h. TransposeGlitch (PNG)

Divides filtered data into byte-level chunks and randomly rearranges them (like pnglitch's Transpose). Chunk boundaries cut through scanlines freely, creating dramatic block-shifting and intra-scanline tearing. Filter type bytes are clamped to 0–4 after rearrangement to keep the PNG decodable. Most striking with Paeth and Sub filters.

var glitch = new G.TransposeGlitch(4);
glitchCanvas.addGlitch(glitch, 'png');

7. GhostGlitch (Block Copy) (JPEG)

Copies a block of scan data from a source offset to a target position. Always uses GlitchValueCollection. Each entry is one copy operation. Offset controls how far back the source is from the target.

var collection = new G.GlitchValueCollection(
  [
    { value: 100 },
    { value: 200 },
    { value: 50 },
  ],
  G.DistributionKind.Sequential,
);
collection.countRange = { min: 2, max: 5 };
collection.valueRange = { min: 0, max: 254 };

var glitch = new G.GhostGlitch(
  new G.Position(50),
  new G.Offset(10),
  collection,
);
glitch.randomizeMode = 'both';

8. Randomization Modes

Each glitch has a randomizeMode property that controls what gets randomized per frame during playback.

glitch.randomizeMode = 'none'; // static, no change
glitch.randomizeMode = 'val';  // randomize values
glitch.randomizeMode = 'pos';  // randomize position
glitch.randomizeMode = 'both'; // randomize both

Below: WidthGlitch with 'val' + ChaosGlitch with 'both'.

var widthGlitch = new G.WidthGlitch(
  new G.Position(0),
  new G.GlitchValue(200),
);
widthGlitch.randomizeMode = 'val';

var chaosGlitch = new G.ChaosGlitch(
  new G.Position(50),
  new G.GlitchValueCollection(
    [{ value: 200 }, { value: 150 }],
    G.DistributionKind.Sequential,
  ),
);
chaosGlitch.val.valueRange = { min: 50, max: 220 };
chaosGlitch.val.countRange = { min: 2, max: 8 };
chaosGlitch.randomizeMode = 'both';

9. Combining Multiple Glitches

Use setGlitches() to apply multiple glitch types. Use addGlitch() and removeGlitch() for individual management. Pass a domainId to target a specific domain.

glitchCanvas.setGlitches([
  new G.WidthGlitch(
    new G.Position(0),
    new G.GlitchValue(200),
  ),
  new G.ChaosGlitch(
    new G.Position(40),
    new G.GlitchValueCollection(
      [{ value: 200 }, { value: 150 }, { value: 100 }],
      G.DistributionKind.Sequential,
    ),
  ),
  new G.QuantumGlitch(
    new G.Position(30),
    new G.GlitchValue(180),
  ),
  new G.QuantumGlitch(
    new G.Position(70),
    new G.GlitchValue(60),
  ),
]);

// Set randomizeMode so each frame varies:
glitchCanvas.glitches[0].randomizeMode = 'val';
glitchCanvas.glitches[1].randomizeMode = 'both';
glitchCanvas.glitches[2].randomizeMode = 'both';
glitchCanvas.glitches[3].randomizeMode = 'both';

10. Playback Controls

glitchCanvas.play();                  // start playback loop
glitchCanvas.pause();                 // stop playback
glitchCanvas.isPlaying;               // boolean, read-only

glitchCanvas.randomize();             // randomize all glitch params, re-render
glitchCanvas.requestRender();         // re-render without randomizing

glitchCanvas.download('output.png');  // export current frame as PNG

11. Manual Re-rendering

When you change glitch parameters at runtime, call requestRender() to update the display.

var glitch = new G.ChaosGlitch(
  new G.Position(50),
  new G.GlitchValue(200),
);
glitchCanvas.addGlitch(glitch);

// Later, change a parameter:
glitch.position = new G.Position(75);
glitch.val = new G.GlitchValue(100);
glitchCanvas.requestRender();

Attributes

buffer-size  number   Number of internal frame buffers (default: 4)
quality      number   JPEG encoding quality, 0.01-1.0 (default: 0.95)

Methods

play()                                              Start playback
pause()                                             Stop playback
load(url: string): Promise<void>                    Fetch and load image from URL
cloneFrom(el: Canvas|Image|Picture): void           Capture from existing element
addGlitch(glitch, domainId?): void                  Add glitch to a domain
removeGlitch(glitch, domainId?): void               Remove glitch from a domain
setGlitches(glitches, domainId?): void              Set glitches for a domain
randomize(): void                                   Randomize all params, re-render
requestRender(): void                               Re-render current params
download(filename?: string): void                   Export frame as PNG
enableDomain(domainId, options?): Promise<void>     Activate a glitch domain
disableDomain(domainId): void                       Deactivate a glitch domain

Properties

isPlaying     boolean               Read-only playback state
glitches      ReadonlyArray         Current glitch list across all domains
fps           number                Frame rate
bufferSize    number                Buffer count
quality       number                JPEG encoding quality (0.01-1.0)
qualityRange  Range<number>|undef   Range for quality randomization
src           string                Image URL
autoplay      boolean               Auto-play on load

JPEG Glitch Types

WidthGlitch(position, val: GlitchValue)
QuantumGlitch(position, val: GlitchValue)
ChaosGlitch(position, val: GlitchValue | GlitchValueCollection)
HuffmanGlitch(position, val: GlitchValue | GlitchValueCollection)
GhostGlitch(position, offset: Offset, val: GlitchValueCollection)

PNG Glitch Types

FilterDataGlitch(position, val: GlitchValue | GlitchValueCollection | DensityValue)
  Replaces bytes in filtered scanline data.
  Propagation direction set by filter type during encoding.

DefectGlitch(position, val: GlitchValue | GlitchValueCollection | DensityValue)
  Deletes bytes and shifts subsequent data forward.
  Filter type bytes clamped to 0-4 for browser safety.

TransposeGlitch(chunkCount?: number)
  Rearranges byte-level chunks in random order.
  Filter type bytes clamped to 0-4 for browser safety.
  Default chunkCount is 4.

GraftGlitch(position, val: GlitchValue | GlitchValueCollection | DensityValue)
  Changes filter type bytes without re-filtering.
  Values are taken modulo 5 (valid filter type range).

CustomFilterGlitch(encoder: FilterFunction, scanlineRange?: Range)
  Re-encodes with a custom filter function.
  Decoder uses standard filters, creating systematic algorithmic deviation.

PNG Filter Type Enum

G.PngFilterType.None    // no propagation
G.PngFilterType.Sub     // horizontal propagation
G.PngFilterType.Up      // vertical propagation
G.PngFilterType.Average // diagonal propagation
G.PngFilterType.Paeth   // wide area propagation

Domain Management

// Enable PNG domain with forced filter type
glitchCanvas.enableDomain('png', { filterType: G.PngFilterType.Sub });

// Set max dimension to control PNG encoding size (default: 1024)
// Large images are scaled down to reduce per-frame compression cost
glitchCanvas.enableDomain('png', {
  filterType: G.PngFilterType.Sub,
  maxDimension: 800,
});

// Disable a domain
glitchCanvas.disableDomain('png');

// JPEG domain is enabled by default after cloneFrom() or load()

Parameter Classes

Position(value: number)                // 0 to 100, normalized position in pool
GlitchValue(value: number)             // 0 to 254, single byte
Offset(value: number)                  // integer, source distance for GhostGlitch
GlitchValueCollection(entries, dist?)  // multi-value with distribution strategy
DensityValue(density, valueRange?, distribution?) // auto-generate sites proportional to pool size
DistributionKind.Sequential            // consecutive pool indices
DistributionKind.Random                // scattered within spread range (default for DensityValue)
DistributionKind.Uniform               // evenly spaced across pool

GlitchValueCollection Config

collection.valueRange = { min: 0, max: 254 };    // value range for randomize()
collection.countRange = { min: 2, max: 8 };      // entry count range for randomize()
collection.spread = { min: 0, max: 100 };        // spread range (Random dist only)
collection.randomize();                          // regenerate entries
collection.resolve(pool, baseIdx);               // get concrete byte indices

DensityValue

var density = new G.DensityValue(0.05, { min: 50, max: 230 });
// 0.05 = target 5% of all pixels, values randomized within [50, 230]
// Distribution defaults to Random (can pass DistributionKind.Uniform etc.)
// Works wherever GlitchValueCollection is accepted
// No need to manually specify entry arrays — count scales with image size
